Install with the mod (recommended)

  1. Install Fabric and Fabric API for Minecraft 1.20.1.
  2. Install the GeoRail PackWiz mod into your mods/ folder.
  3. Open config/geopackwiz.json and set: 
    {
  "remoteConfigUrl": "https://packwiz.justnoone.eu/client_config.json"
}
  4. Join the GeoRail server — the pack downloads and updates itself automatically.

The pack is verified by SHA-1 on every update, so tampering is detected.
